08Manual platform — native invite checklist/invite/[token]/kitphase: platforms · manual flow

Shared frame for all manual platforms (ManualInviteFlow): objective, verify-identities rail, numbered steps with per-step primary actions, then a completion gate. Step copy is configured per platform (Kit, Beehiiv, Pinterest, Shopify…), so shown steps are structural; Shopify adds client-side form fields (e.g. store domain, collaborator code). Submitting hands back to the request with ?view=connect.
