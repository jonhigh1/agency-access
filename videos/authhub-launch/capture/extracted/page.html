About

What is Agent Motion?

Agent Motion gives coding agents a catalog of open-source, editable video building blocks. Instead of generating every animation from scratch, an agent can discover tested scenes for product demos, interface walkthroughs, charts, terminal recordings, launches, and more.

Today, Agent Motion components are built for Remotion and delivered as editable TypeScript source. Codex, Claude Code, Cursor, and other coding agents can inspect each component, choose it by intent, and install it directly into a video project without an account or API key.

All 33 registry components passed TypeScript validation and first-, middle-, and last-frame render checks. Registry updated August 28, 2026.
