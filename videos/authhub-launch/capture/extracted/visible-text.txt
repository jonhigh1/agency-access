[span] About
[h2] What is Agent Motion?
[strong] Agent Motion gives coding agents a catalog of open-source, editable video building blocks.
[p] Instead of generating every animation from scratch, an agent can discover tested scenes for product demos, interface walkthroughs, charts, terminal recordings, launches, and more.
[p] Today, Agent Motion components are built for Remotion and delivered as editable TypeScript source. Codex, Claude Code, Cursor, and other coding agents can inspect each component, choose it by intent, and install it directly into a video project without an account or API key.
[p] All
[p] registry components passed TypeScript validation and first-, middle-, and last-frame render checks. Registry updated
[time] August 28, 2026
